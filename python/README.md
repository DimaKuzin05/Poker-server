# 🃏 Покерный Клиент-Сервер, Streamlit Дашборд и Детектор Карт на Python

Полноценный комплекс программ для игры в покер (Texas Hold'em), математического анализа вероятностей побед (Win Rate Equity), визуализации данных в Streamlit и распознавания игральных карт через веб-камеру с использованием компьютерного зрения OpenCV.

---

## 📁 Структура проекта

| Файл | Описание |
| :--- | :--- |
| `poker_server.py` | Покерный сервер с REST API, игровой логикой, расчетом Win Rate и базой данных SQLite (`poker_stats.db`). |
| `streamlit_app.py` | Интерактивный веб-дашборд на Streamlit с тепловой картой 13x13, графиками банкролла, аналитикой по позициям и калькулятором шансов. |
| `card_detector.py` | Программа компьютерного зрения (OpenCV) для распознавания игральных карт через камеру и наложения HUD с процентом побед. |
| `poker_client.py` | Интерактивный консольный клиент для игры за столом против ботов. |
| `poker_equity.py` | Высокоскоростной модуль оценки покерных комбинаций и симуляции методом Монте-Карло. |
| `poker_stats.db` | База данных SQLite с историей раздач и статистикой игроков. |
| `requirements.txt` | Список зависимостей Python (`streamlit`, `opencv-python`, `pandas`, `plotly` и др.). |

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск покерного сервера
Сервер управляет раздачами, вычисляет вероятность побед на каждой улице и сохраняет данные в базу:
```bash
python poker_server.py
```
Сервер запустится на `http://localhost:8080`.

### 3. Запуск визуализации в Streamlit
Запуск аналитического дашборда:
```bash
streamlit run streamlit_app.py
```
Откроется в браузере по адресу `http://localhost:8501`.  
**Возможности в Streamlit:**
- 13x13 тепловая матрица стартовых рук с процентом побед (AA, KK, AKs и др.).
- Интерактивный калькулятор эквити Монте-Карло для любых карманных карт и карт борда.
- Графики процента побед по позициям за столом (BTN, CO, MP, UTG, SB, BB).
- Таблица последних сыгранных раздач с фильтрами.
- Генератор тестовых раздач для мгновенного наполнения аналитики.

### 4. Запуск программы распознавания карт через камеру
```bash
python card_detector.py
```
**Как работает:**
1. Захватывает видеопоток с веб-камеры (`cv2.VideoCapture`).
2. Применяет пороговую бинаризацию и поиск 4-угольных контуров карт.
3. Выполняет перспективное преобразование (`warpPerspective`) для выравнивания карты.
4. Распознает ранг (2..A) и масть (♠ ♥ ♦ ♣) по цветовым и структурным признакам.
5. Автоматически рассчитывает текущий Win Rate обнаруженных карт в реальном времени.
6. Клавиша **`S`** отправляет распознанные карты прямо на покерный сервер!
7. Клавиша **`Q`** — выход из программы.

### 5. Запуск игрового клиента
Для участия в игре в роли человека:
```bash
python poker_client.py
```
Позволяет совершать ставки Check, Call, Raise, Fold с выводом шансов на победу в реальном времени.
