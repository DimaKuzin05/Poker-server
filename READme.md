# 🃏 Poker Lab: Покерный Клиент-Сервер, Win Rate Аналитика в Streamlit и OpenCV Камера

Учебный инженерный проект, демонстрирующий разработку распределенной системы для Техасского Холдема (Texas Hold'em), включающей:
1. **Покерный сервер** с REST API, симуляцией логики ботов и базой данных SQLite.
2. **Аналитический дашборд на Streamlit** с тепловой картой 13x13 стартовых комбинаций, графиками позиций и расчетом эквити Монте-Карло.
3. **Модуль компьютерного зрения (OpenCV)** для распознавания физических карт через веб-камеру с наложением HUD и расчетом шансов на победу.
4. **Интерактивный консольный клиент** на Python для игры против ботов.
5. **Интерактивный веб-интерфейс** на чистом TypeScript (0% React) со столом, симулятором камеры и аналитикой.

### 3. Запуск аналитического дашборда (`streamlit_app.py`)

В **новом окне терминала** запустите дашборд:
```bash
cd python
streamlit run streamlit_app.py
```
Приложение автоматически откроется в браузере по адресу:
👉 **`http://localhost:8501`**

**Что доступно в дашборде Streamlit:**
- **KPI-метрики**: общее количество сыгранных раздач, суммарный Win Rate Hero в %, количество побед/поражений, чистый профит в фишках.

- **Калькулятор эквити Монте-Карло**: расчет шансов победы, ничьей и поражения для выбранных карманных карт и карт стола против 1–8 оппонентов.

### 5. Запуск отдельного Python-детектора (`card_detector.py`)

В **новом окне терминала** запустите программу распознавания карт:
```bash
cd python
python card_detector.py
```

**Горячие клавиши управления:**
- **`S`** — отправить найденные карты на локальный сервер.
- **`E`** — пересчитать эквити.
- **`Q`** — выйти из программы.

**Алгоритм работы компьютерного зрения:**
1. Захват кадра с камеры через `cv2.VideoCapture`.
2. Перевод в градации серого (`cv2.cvtColor`), размытие по Гауссу и пороговая бинаризация (Otsu Threshold).
3. Поиск 4-угольных контуров карт по площади и пропорциям сторон.
4. Преобразование перспективы (`cv2.warpPerspective`) для выравнивания карты в стандартный размер 200x300 пикселей.
5. Анализ угловой зоны карты для оценки ранга и масти.
6. Вычисление эквити найденных карт на лету и отображение HUD.

Python-детектор использует простые эвристики OpenCV, которые могут ошибаться на реальных картах и при сложном освещении. Для браузерного сканирования используйте описанный выше OCR-процесс и проверяйте результат.

## 🗄 Схема базы данных SQLite (`poker_stats.db`)

База данных содержит две связанные таблицы:

### 1. Таблица `games` (История игр)
```sql
CREATE TABLE games (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    pot INTEGER,              -- Сумма финального банка ($)
    board_cards TEXT,         -- Карты стола через запятую (например 'Ah,Kd,7c,2s,Jd')
    winner_name TEXT,         -- Имя победителя
    winner_hand TEXT          -- Выигрышная комбинация (например 'Две пары')
);
```

### 2. Таблица `hand_stats` (Статистика игроков по раздачам)
```sql
CREATE TABLE hand_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    game_id INTEGER,          -- Внешний ключ на games(id)
    player_name TEXT,         -- Имя игрока (Hero, Бот Алексей и т.д.)
    hole_cards TEXT,          -- Карманные карты (например 'As,Kd')
    starting_hand TEXT,       -- Код стартовой руки (например 'AA', 'AKs', '72o')
    position TEXT,            -- Позиция за столом (BTN, CO, MP, UTG, SB, BB)
    won INTEGER,              -- 1 = победа, 0 = поражение
    profit INTEGER,           -- Изменение стека за раздачу ($)
    final_hand TEXT,          -- Итоговая 5-карточная комбинация
    win_rate_equity REAL,     -- Расчетное эквити на момент префлопа (%)
    FOREIGN KEY(game_id) REFERENCES games(id)
);
```

## 🧠 Математический алгоритм расчета Win Rate (Монте-Карло)

Расчет шансов на победу в модуле `poker_equity.py` использует метод случайных статистических испытаний (Monte Carlo Simulation):

$$\text{Win Rate} = \frac{W + \frac{T}{2}}{N} \times 100\%$$

Где:
- $W$ — количество симуляций, в которых рука игрока оказалась строго старше рук всех оппонентов.
- $T$ — количество симуляций с разделом банка (Split Pot / ничья).
- $N$ — общее число итераций симуляции (по умолчанию $1000$–$2000$).

**Этапы алгоритма:**
1. Из стандартной 52-карточной колоды исключаются известные карты (карманные карты игрока и уже открытые карты борда).
2. На каждой итерации из оставшейся колоды случайно сдаются недостающие карты борда (до 5 штук) и карманные карты оппонентам.
3. Оценщик комбинаций находит наилучшие 5-карточные сочетания для каждого участника из доступных 7 карт.
4. Фиксируется победа, поражение или ничья.
5. За доли секунды алгоритм выполняет тысячи симуляций, обеспечивая точность до десятых долей процента.

## 🌐 REST API эндпоинты сервера

Покерный сервер (`poker_server.py`) предоставляет следующие HTTP-эндпоинты:

| Метод | Путь | Описание | Пример ответа / тела |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/table` | Получить текущее состояние стола (карты, банк, улицу, ставки, шансы Hero). | `{"stage": "FLOP", "pot": 60, "hero_equity": 68.4, ...}` |
| `POST` | `/api/action` | Совершить действие игроком. | `{"action": "raise", "amount": 70}` |
| `POST` | `/api/new_hand` | Начать новую раздачу карт. | `{"status": "ok", "stage": "PREFLOP"}` |
| `POST` | `/api/inject_cards` | Записать в игру карты, распознанные камерой OpenCV. | `{"cards": ["As", "Kd"]}` |
| `GET` | `/api/stats` | Получить сводную статистику побед и профита из SQLite. | `{"total_hands": 120, "win_rate": 58.3, ...}` |
| `POST` | `/api/seed` | Наполнить базу данных пачкой симулированных раздач. | `{"count": 50}` |
